ตั้งค่าการเชื่อมต่อ Google Sheets & Google Drive

ระบบบันทึกข้อมูลอย่างถาวรผ่าน Google Apps Script Webhook API เพื่อให้งานและข้อมูลส่งตรงเข้า Google Sheet ของท่านทันที

คำแนะนำในการติดตั้ง Google Sheet API:
  1. สร้าง Google Sheets ใหม่บน Google Drive ของท่าน
  2. ไปที่ ส่วนขยาย (Extensions) > Apps Script
  3. วางโค้ด `doPost(e)` เพื่อรับ JSON Payload และต่อท้ายแถวใน Sheet
  4. กด Deploy > New Deployment > Web App (สิทธิ์: Anyone)
  5. นำ Webhook URL ที่ได้มาวางใส่ในช่องด้านบนนี้
